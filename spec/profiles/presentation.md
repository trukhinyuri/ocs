# Human, machine and assistive surfaces

**U-01 Placement.** A host decides where a contribution appears and when it is activated. `ocs.presentation/0.1` declares a [surface descriptor](../../schemas/profile-data.schema.json#/$defs/surface). A package may publish these under `org.ocs.surfaces` for inspection before activation. Name the slot, available operations, representation and required capabilities. Discovering a surface grants no operation. CLI, TUI, GUI, agent and automation read the same authoritative states and consequences. A client may support a subset, with a visible explanation. Keep headless work available if the renderer fails.

**U-02 Representation.** A declarative surface describes data, fields, actions, semantic labels and progress. The host provides its design language, locale, keyboard handling and accessibility tree. For the portable declarative representation, `view` includes a title, a JSON Schema for its current values and an ordered list of labeled, versioned actions. `entry` can instead name an admitted package resource containing that view. Validate the values and intersect each action with the surface’s operation list and current grants. Schema titles, descriptions and read-only annotations help a host render a keyboard-accessible form or terminal representation. New representation types can use a namespaced extension and a negotiated feature. Host-rendered content is inert until an explicitly bound action is admitted. Unknown mandatory controls make the affected action unavailable. For a custom web surface pin source/integrity, isolate origin/process, restrict navigation and egress, and validate each incoming event's origin, instance, generation and schema. Do not pass host credentials or privileged objects to the page. A native, terminal, voice or hardware UI uses an explicitly supported platform binding, a separate process/window or a verified link. When safe embedding is unavailable, show the alternate path. A product may keep all of its own native UI.

**U-03 Interaction.** `surface.open` binds a surface to the instance and scoped context. `surface.event` is an untrusted request for one declared action. Route it through the same admission checks as the public API. A trusted host-owned confirmation identifies recipient, resource, amount and exact effect when required. Closing a panel unsubscribes and restores focus. Stale callbacks from a closed or replaced instance are ignored. Closing UI does not implicitly cancel a durable job. Errors, retry, resume, send-new-request and grant-permission must be distinguishable by text and accessible controls, including at narrow widths and increased font size. Account availability, quota freshness, reset eligibility and paid terms must be discoverable without inferring meaning from color.

**U-04 Agent surface.** Supply machine-readable operation contracts and short descriptions for discovery. Optional workflow instructions load on selection, and may describe how to combine existing tools. Instructions, tool descriptions, hook text and model outputs do not grant permissions. Test a direct request, an indirect request, a continuation by ID and a negative request which must not cause a write. Validate packages, execution environments and account authorization independently.
