# Models, agent messages and artifacts

**G-01 Participants.** A model produces content. A runtime receives a request and sends a response. A policy selects the receiving peer and permissible actions. `ocs.agents/0.1` defines `agent.exchange` as an export over the ordinary OCS call binding. The smallest native interoperability path is UTF-8 text and one response. Peers may negotiate structured data, files, audio, images and stream support. Vendor-specific inference protocols remain behind scoped adapters. Between native peers only the OCS application protocol is required.

**G-02 Correlation.** Use a [message](../../schemas/profile-data.schema.json#/$defs/message) with a stable message ID and ordered parts. A reply names the original ID. A context ID is optional. A durable task has a separate job ID and owner. Explicitly represent immediate answers, requests for missing facts, a need for human authority, partial results and terminal outcomes. Preserve the provenance of peer content when passing it to a model. A claimed sender, role or quote cannot supply user authorization or alter system policy. Distinguish unconfirmed delivery from failure of the task. An unsupported required part must be rejected or transformed by explicit agreement.

**G-03 Budget.** Bound the complete exchange by deadline, turns, fan-out, concurrency, bytes, cost and a stop rule. Use the message’s `budget` for remaining turns, admissible fan-out, bytes, concurrency and cost. A receiver intersects these with its local policy. A delegated caller reserves a share from the parent budget before sending parallel work. `accept` lists supported reply media types. Treat absent constraints as subject to local limits. Pass the remaining budget at each hop. Count tokens per tokenizer/model and show unknown pricing honestly. Deduplicate identical message delivery within the promised retention scope. The same ID with changed content is a conflict. Do not silently retry an uncertain paid generation. Respect cancellation and credit limits. Exit a no-progress loop with a structured reason and retained evidence. Do not forward full histories, system prompts, private reasoning or credentials by default. A peer may offer references or compact summaries when that preserves the necessary facts.

**G-04 Testing.** Test A → B → A with a synthetic fact accessible only to B. Cover request, reply, clarification, partial input, duplicate, denial and cancellation. Pin actual models, participants and accounts. Distinguish a deterministic transport fixture, a model on the local machine, a loopback network process and real remote inference. Benchmark direct inference, relaying a full admissible history and relaying only required facts on the same quality task. Report quality, bytes, model-specific token counts, first useful output, end-to-end time and cost. Specialized latent representations or cache sharing require compatible runtimes and measurement. They do not replace the portable contract. A text-only participant is not required to implement tool calling.
